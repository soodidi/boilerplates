# Smoke test avant soumission (GLB-009)

À dérouler sur la matrice minimale : minSdk (Android 8.0), dernière version d'Android, un petit téléphone, un grand téléphone (et une tablette si supportée).

- [ ] L'app démarre sans crash, en mode clair et sombre
- [ ] Liste des notes : chargement, recherche, réessayer après erreur
- [ ] Création d'une note : titre vide refusé, note ajoutée et confirmée par un message
- [ ] Mode avion : message d'erreur et bouton Réessayer
- [ ] Taille de police maximale : rien n'est tronqué ni superposé
- [ ] TalkBack : chaque élément est lisible et activable
